# Witcher 3 VR – Remastered fork, v0.9.8v2-remastered.1

First release of this fork of [Witcher 3 VR](https://github.com/tig3rmast3r/witcher3-vr) by
tig3rmast3r. All credit for the mod goes to him; this fork adds support for The Witcher 3
Remastered on top of his v0.9.8v2 release.

## Game versions

- **The Witcher 3 Remastered, patch 5.01** (GOG; tested): experimental. Stereo or Mono with the
  game's FXAA. TAAU, DLSS, ray tracing, AER + AFW, OptiScaler, ReShade and OFXR are not ported to
  5.x yet.
- **The Witcher 3 Next-Gen 4.04**: as in the original v0.9.8v2, plus the fixes below.

## Changes compared to the original v0.9.8v2

- Remastered 5.01 support: game hooks, stereo rendering, HUD, menus, cutscenes and the OpenXR path.
  Unknown game builds are detected and the game hooks stay disabled.
- Full VR cutscenes: sky and trees no longer stay attached to the head in cutscenes that reuse the
  game camera (4.04 and 5.x).
- Cutscene and dialogue camera lights keep the camera's direction instead of following head turns
  like a head lamp (4.04 and 5.x).
- The recenter key is configurable: `[openxr] recenter_key` in `witcher3vr.ini` (default `F9`; for
  example `F5` or `Space`).
- Launcher: detects Remastered 5.x. **Configure Settings for VR** applies the 5.x VR settings there
  (FXAA; ray tracing, light shafts, frame generation, low-latency modes and HDR off) and keeps all
  other settings; only the modes that work on 5.x can be saved.
- With AUTO resolution, the launcher reads the headset's recommended resolution on every Save &
  Launch. Without a reachable headset it keeps the last known resolution instead of failing, and
  asks before launching.
- On 5.x the HUD editor setup no longer needs `dx12filelist.txt` (5.x loads the menu XML itself).
- The mod's game scripts compile on 5.x (horse and boat camera wrappers use the full state class
  names).
- Default render mode is **Stereo - No AA / FXAA** on both game versions (AER + AFW needs the
  optional PureDark plugin). Existing settings with AER + AFW switch to the matching Stereo mode when
  the plugin is not installed.

## Not included

- **PureDark AFW** (`PDAFWPlugin.dll`), needed only for AER + AFW on 4.04. Copy it from the
  [original release](https://github.com/tig3rmast3r/witcher3-vr/releases) into `bin\x64_dx12`, or
  use a Stereo or Mono mode.
- **Fast Transitions DLC** (optional, 4.04). Also in the original release (`dlc` folder).
- NVIDIA DLSS5 files, as in the original release.

## Installation

1. Extract the archive into the game folder (the one containing `bin`, `content` and `mods`); merge
   and overwrite.
2. Start `bin\x64_dx12\Witcher3VRLauncher.exe`.
3. Press **Configure Settings for VR** once (it backs up your game settings first; **Restore
   Original Settings** brings them back).
4. Press **Save & Launch**.

## Known issues on 5.x

- Only FXAA anti-aliasing; a higher render resolution helps (Virtual Desktop "Ultra" or above).
- Distant water can switch between blue and white with the head pose.
- AMD GPUs need Adrenalin 26.9.2 or newer, otherwise some grass renders black (with or without the
  mod).
- Windows Defender may flag the unsigned `dxgi.dll` as a false positive.

Full list: [docs/remaster-open-issues.md](https://github.com/joschi127/witcher3-vr/blob/remaster/docs/remaster-open-issues.md).
