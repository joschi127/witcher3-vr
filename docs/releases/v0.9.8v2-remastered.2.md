# Witcher 3 VR – Remastered fork, v0.9.8v2-remastered.2

Second release of this fork of [Witcher 3 VR](https://github.com/tig3rmast3r/witcher3-vr) by
tig3rmast3r. All credit for the mod goes to him; this fork adds support for The Witcher 3
Remastered on top of his v0.9.8v2 release. Many of the 5.x improvements in this release come from
[kaarele/witcher3-remastered-vr](https://github.com/kaarele/witcher3-remastered-vr) (MIT), taken
over feature by feature.

## Game versions

- **The Witcher 3 Remastered, patch 5.01** (GOG; tested): experimental. Stereo or Mono with the
  game's FXAA, or with **FSR per eye** (new). TAAU, ray tracing, AER + AFW, OptiScaler, ReShade
  and OFXR are not ported to 5.x yet. DLSS per eye exists but is untested in this fork (see below).
- **The Witcher 3 Next-Gen 4.04**: as in the original v0.9.8v2, plus the fixes of this fork.

## Changes compared to v0.9.8v2-remastered.1

- **FSR per eye on 5.x** (launcher switch **FSR per eye (5.x)**): uses the game's FSR instead of
  FXAA, with one FSR history per eye, so the eyes no longer ghost into each other. Smoother edges and
  much less GPU load at high resolutions, the image is a little softer. Works with the FidelityFX
  path the game uses on newer AMD GPUs and with its built-in FSR 2 on other GPUs. Off = FXAA as
  before.
- **Better temporal quality on 5.x:** both eyes of a stereo pair use the same jitter and noise
  pattern, and moving characters keep their motion vectors in the second eye (no smearing there).
- **Lower CPU load on 5.x:** a new descriptor metadata store and render-thread trims (about -27 %
  CPU time per frame in our benchmark), and the game thread no longer waits for each stereo pair to
  finish rendering (one pair of run-ahead) while both eyes still show the same animation poses.
- **Close cameras on 5.x:** **Configure Settings for VR** now also sets the game's close exploration
  and combat cameras (recommended for VR). The 5.x default "Modern" camera re-frames while walking,
  which in VR shows as the camera jumping between far and near when you start or stop walking. When
  updating from v0.9.8v2-remastered.1, press the button once more, or choose the close cameras in the
  game's camera options.
- **Square render sizes on 5.x:** an exactly square per-eye size (for example full FOV in Virtual
  Desktop) made the game crash while loading or show the sky only in a corner with an upscaler; the
  mod now renders 8 pixels less in height in that case.
- **DLSS per eye on 5.x** (`[engine] temporal_backend=dlss` in `witcher3vr.ini`, Anti-aliasing =
  DLSS in the game): one DLSS history per eye. Tested by kaarele on NVIDIA; not tested in this fork
  and not offered in the launcher yet.
- **Linux/Proton (Steam and Heroic/GOG):** the release zip can be installed with the Linux tool from
  this repository; see [LINUX.md](https://github.com/joschi127/witcher3-vr/blob/remaster/LINUX.md).
  Its `configure --aa fsr` sets the same FSR per eye as the launcher.
- All new 5.x options can be switched off one by one in `witcher3vr.ini` (described in
  `Witcher3VR/config/witcher3vr.example.ini`); 4.04 is unchanged by them.

## Not included

- **PureDark AFW** (`PDAFWPlugin.dll`), needed only for AER + AFW on 4.04. Copy it from the
  [original release](https://github.com/tig3rmast3r/witcher3-vr/releases) into `bin\x64_dx12`, or
  use a Stereo or Mono mode.
- **Fast Transitions DLC** (optional, 4.04). Also in the original release (`dlc` folder).
- NVIDIA DLSS5 files, as in the original release.

## Installation

1. Extract the archive into the game folder (the one containing `bin`, `content` and `mods`); merge
   and overwrite.
2. Start `bin\x64_dx12\Witcher3VRLauncher.exe`.
3. Press **Configure Settings for VR** once, also when updating from v0.9.8v2-remastered.1 (it sets
   the close cameras; it backs up your game settings first, and **Restore Original Settings** brings
   them back).
4. Optional on 5.x: tick **FSR per eye (5.x)**.
5. Press **Save & Launch**.

## Tips for 5.x

- With FSR per eye a high render resolution pays off. If 90 Hz is not reached at full FOV, reduce
  the FOV in Virtual Desktop slightly (for example 80 % horizontal, 70 % vertical) or use the "High"
  quality instead of "Ultra"; the launcher's AUTO resolution follows the headset's recommendation.

## Known issues on 5.x

- Distant water can switch between blue and white with the head pose.
- AMD GPUs need Adrenalin 26.9.2 or newer, otherwise some grass renders black (with or without the
  mod).
- Windows Defender may flag the unsigned `dxgi.dll` as a false positive.

Full list: [docs/remaster-open-issues.md](https://github.com/joschi127/witcher3-vr/blob/remaster/docs/remaster-open-issues.md).
