# Smoke test for the Remaster (5.01) on Linux/Proton: the Windows smoke-continue-remaster.txt
# with Linux timings. Under Proton the game polls XInput (no GameInput redistributable), so the
# test mode's virtual XInput gamepad drives it. Measured on a laptop iGPU under GE-Proton: main
# menu ready by ~30 s, first stereo frame ~48 s after the first Present (16 s of loading after
# Continue at 32 s). Each capture stalls the game for seconds (two frames and both XR eye images
# are written as PNG), so every step after a capture waits 6-8 s, and the fallback quit comes
# 15 s after the menu exit. Ends at ~126 s.
# In gameplay the game may poll XInput only a few times per second under Proton; the test
# mode holds every scripted state for two reads, so short taps still arrive.
